One ripe mango, halved, glistening with fresh juice and dripping — a photographic-style close-up that tastes of a single ingredient. Nothing else competes for attention: just the mango, its golden flesh, and the juice running down it.

`main.ts` validates the 1024×1024 PNG (under 1 MiB) and copies it to the output directory as `entry.png`, using only the Node.js standard library.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
