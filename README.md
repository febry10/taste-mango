One ingredient, one picture: a single ripe mango, halved, its golden flesh glistening with fresh juice, a ribbon of juice dripping from the cut — a photograph-style close-up that you can taste at a glance. The image (`mango.png`, 1024×1024, under 1 MiB) is validated and copied to the output directory as `entry.png` by `main.ts`, using only the Node.js standard library.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
